## 1. Executive Summary & Architecture

The **Trade-War News Alerter** (Fiverr Production Edition) is an autonomous multi-agent AI system designed to monitor, validate, and dispatch real-time geopolitical and export risk intelligence for Indian businesses across five strategic corridors:
- **LATAM** (Latin America)
- **CIS** (Commonwealth of Independent States)
- **Africa**
- **MENA** (Middle East & North Africa)
- **EU** (European Union)

### Workflow Lifecycle
```text
[Cron Schedule: 06:00 AM IST]
           │
           ▼
[Google Sheets: Fetch Active Subscribers & Target Corridors]
           │
           ▼
[Corridor Loop: LATAM ➔ CIS ➔ Africa ➔ MENA ➔ EU (SplitInBatches)]
           │
           ▼
[Perplexity API: Targeted 24h Real-Time Trade & Sanction Search]
           │
           ▼
[Analyst Agent: Evaluates Severity & Formulates 1-5 Risk Payload]
           │
           ▼
[Critic Agent: Dual-Agent Fact Verification & Hallucination Audit]
           │
           ▼
[JavaScript Parser: Formats Output & Enforces Strict JSON Integrity]
           │
           ▼
[Supabase DB: Writes Diagnostic Trace to 'risk_logs' Table]
           │
           ▼
[Google Sheets: Appends Clean Row to 'Risk Log' Tab]
           │
           ▼
[Subscriber Matcher: Filters Active Exporters for Current Corridor]
           │
           ▼
      [Is Risk Score >= 4?]
      /                  \
    YES                   NO
    /                      \
[Picky Assist:         [Skip WhatsApp Dispatch]
 WhatsApp Push Alert]     │
    \                      /
     ▼                    ▼
      [Loop to Next Corridor]
```

## 5. Step 3: Supabase Audit Trail Setup

Execute this SQL query in your **Supabase SQL Editor**:

```sql
CREATE TABLE IF NOT EXISTS public.risk_logs (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL,
    corridor TEXT NOT NULL,
    risk_score INTEGER NOT NULL,
    headline TEXT NOT NULL,
    summary JSONB,
    raw_news_data TEXT,
    alert_sent BOOLEAN DEFAULT false,
    analyst_result TEXT,
    critic_result TEXT
);

CREATE INDEX IF NOT EXISTS idx_risk_logs_corridor ON public.risk_logs(corridor);
CREATE INDEX IF NOT EXISTS idx_risk_logs_score ON public.risk_logs(risk_score);
CREATE INDEX IF NOT EXISTS idx_risk_logs_created_at ON public.risk_logs(created_at DESC);
```

In n8n, open node **Create a row**, link your Supabase credential, and select table `risk_logs`.

## 6. Step 4: AI Risk Taxonomy & Intelligence

| Score | Classification | Real-World Operational Triggers | Action |
| :--- | :--- | :--- | :--- |
| **1** | Normal / Safe | No major updates or standard operational noise. | Log Only |
| **2** | Low Impact | Preliminary political statements or general diplomatic commentary. | Log Only |
| **3** | Moderate Concern | Proposed tariff hikes, antidumping probes, draft quotas. | Log Only |
| **4** | High Risk | Emergency import caps, active tariffs, customs restrictions. | **SEND WHATSAPP** |
| **5** | Critical / Severe | Complete bans, embargoes, broad international sanctions. | **SEND WHATSAPP** |

- **Analyst Agent:** Generates 1-5 score, headline, and 3-bullet action plan.
- **Critic Agent:** Audits the Analyst's output against raw Perplexity data to eliminate hallucinations.
